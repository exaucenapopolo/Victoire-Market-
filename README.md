# Victoire Market

Marketplace locale de Bertoua. Monorepo pnpm.

## Structure
- `apps/web` — front React + Vite
- `apps/api` — API Node/TypeScript
- `packages/shared` — types du domaine, moteur de tarification, machine à états
- `packages/validation` — schémas de validation partagés

## Commandes
- `pnpm install`
- `pnpm test`
- `pnpm typecheck`
- `pnpm build`
